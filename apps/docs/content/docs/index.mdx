OpenMausBot is a desktop chat app where every contact is a real AI agent. Each bot can have its own model, personality, tasks, connected apps, and computer.

## The short version

- **Bring your own agents.** OpenMausBot runs supported agent CLIs installed and authenticated on your machine.
- **Local first.** Conversations, credentials, configuration, and agent processes stay on your computer by default.
- **Agents with hands.** Give a bot a local computer, an isolated VM, a cloud desktop, or a hardened VPS container.
- **Approval aware.** Risky actions and questions appear as cards in the conversation.
- **Open source.** The source is available under Apache License 2.0.

<Callout type="info" title="Early, but real">
  OpenMausBot is moving quickly. Use the changelog for release-level changes and the GitHub repository for work that has not shipped yet.
</Callout>
